# 2D Numerical Modelling of Thermal Convection in the Earth's Mantle

This project focuses on the **numerical modelling of thermal convection in the Earth's mantle using Python**. A two-dimensional computational model is developed to investigate heat transfer through thermal diffusion and buoyancy-driven fluid motion under the Boussinesq approximation. Using finite-difference methods, the model simulates temperature evolution, velocity fields, and convection patterns. The project also examines the influence of the **Rayleigh number** on convection intensity and heat transport, providing insight into the physical processes governing mantle dynamics.

**Tools & Technologies:** Python, NumPy, SciPy, Matplotlib

**Keywords:** Mantle Convection, Computational Geophysics, Boussinesq Approximation, Finite-Difference Method, Rayleigh Number, Heat Transfer
